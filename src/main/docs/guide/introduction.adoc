Micronaut JAX-RS is an implementation of https://jakarta.ee/specifications/restful-ws/4.0/[Jakarta RESTful Web Services 4.0] (JAX-RS) on top of the Micronaut HTTP server and client. Resources, providers, features and `Application` subclasses written against the `jakarta.ws.rs` API run in a Micronaut application, next to Micronaut controllers, beans and configuration.

The server and the client pass the Jakarta RESTful Web Services 4.0 TCK, with and without the reflection module, see <<supportedApi, Specification Support>>. The few places where the implementation deliberately differs from the specification are listed there.

TIP: See the guide for https://guides.micronaut.io/latest/micronaut-jaxrs-jdbc.html[Micronaut JAX-RS] to learn more.
