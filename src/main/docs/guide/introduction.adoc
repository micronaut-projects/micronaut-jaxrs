Micronaut JAX-RS is a Micronaut-native implementation of Jakarta RESTful Web Services (JAX-RS) for building Micronaut server and client applications with familiar JAX-RS annotations and types.

It helps migrate existing JAX-RS applications, supports teams that prefer the JAX-RS programming model, and can be used with the aggregate Jakarta REST compliance modules when broader specification behavior is required.

TIP: See the guide for https://guides.micronaut.io/latest/micronaut-jaxrs-jdbc.html[Micronaut JAX-RS] to learn more.
